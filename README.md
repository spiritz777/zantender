# ZanTender AI

Локальный Telegram MVP для демонстрации подбора и анализа тендеров Казахстана. Данные хранятся в SQLite; Docker, Redis, PostgreSQL и реальный scraper не нужны.

По умолчанию включён `DEMO_MODE=true`: в нём работает полный пользовательский сценарий с локальными тестовыми тендерами и детерминированным AI. Для демо не нужны `GEMINI_API_KEY` и доступ к AI API.

## Быстрый запуск в Windows PowerShell

1. Проверьте Python 3.12+:

   ```powershell
   python --version
   ```

2. Создайте виртуальное окружение:

   ```powershell
   python -m venv .venv
   ```

3. Активируйте его:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Если PowerShell блокирует скрипты, один раз выполните:

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

4. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

5. Создайте `.env`:

   ```powershell
   Copy-Item .env.example .env
   ```

   Впишите токен Telegram-бота из BotFather:

   ```dotenv
   BOT_TOKEN=123456:telegram-bot-token
   DEMO_MODE=true
   ```

6. Запустите приложение:

   ```powershell
   python run.py
   ```

При первом запуске автоматически создаются `data`, `uploads`, `logs`, SQLite-база и применяются миграции. Если `BOT_TOKEN` не задан, приложение корректно подготовит локальную базу, но polling Telegram не начнётся.

## DEMO-сценарий для заказчика

1. Откройте бота и отправьте `/start`.
2. Нажмите `🏢 Настроить компанию`.
3. Отправьте: `Компания занимается разработкой сайтов`.
4. Нажмите `🎯 Подходящие тендеры`.
5. Бот покажет `Разработка корпоративного сайта`, `2 450 000 ₸` и `Соответствие 91%`.
6. Нажмите `🔎 Анализировать`. Бот сохранит и разберёт локальный demo-документ, показав оценку `82/100`.
7. Нажмите `⚖️ Задать вопрос` и отправьте: `Почему этот тендер мне подходит?`.
8. Откройте `🔔 Мои уведомления` и нажмите `🧪 Тестовое уведомление` — бот пришлёт `🔔 НОВЫЙ ТЕНДЕР!`.

В этом же меню доступны история анализов и ручной анализ собственных PDF/DOCX/текстовых спецификаций.

## Архитектура demo-feed

Telegram handlers не зависят от способа получения тендеров. Они используют `TenderCatalogService`, который принимает интерфейс `TenderSource`. Сейчас внедрён [DemoTenderSource](app/tenders/demo_source.py); позже его можно заменить реализацией `RealTenderSource` для API без переделки matching или UX.

`DEMO_MODE=false` переключает AI-слой на Gemini. В таком режиме нужно указать `GEMINI_API_KEY` в `.env`; реальный источник тендеров намеренно не реализован в рамках MVP.

## Проверка

```powershell

```

Тесты проверяют обработку документов, базу, меню и полный offline demo-flow: профиль → matching 91% → анализ 82/100 → AI-консультант → настройки уведомлений.
